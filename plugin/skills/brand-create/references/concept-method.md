# Concept method

From a narrative to three concept lines. Rules: `brd:DEC-01`, `brd:CNC-01`, `brd:CNC-02`, `brd:CNC-03`. Sources: `research/brd-research.md` A9 and A27 (paraphrased; no text copied). No existing tool found in research has an explicit narrative-to-metaphor method; this is the kit's own.

## 1. Narrative to essence

Read the narrative and write, in the brief:

- **Essence:** what the thing does for whom, in one plain sentence.
- **Tension:** the problem or before-and-after the narrative describes.
- **Tone:** 3 to 5 words the narrative earns (quote the phrase that earns each one, as a short note).
- **Avoid:** what the user rules out, plus the category's clichés (step 3).
- **Positioning (scope B and C):** draft the `positioning` line and the `own-word` from the essence and the tension (`brd:POS-01`; `brand-core/references/positioning.md`). Suggest both in the one step 1 question; mark them `assumed` if the user does not answer.

Archetype is optional: name a primary one only if it sharpens the tone, otherwise `none`. It is a shortcut into strategy, not a replacement for one (A27), and never the reason for a colour (`brd:POS-04`).

Do not justify colour or shape with colour-psychology claims such as "blue means trust"; research found them to be folklore (rknall, track B), and the colour evidence table in `brand-core/references/colour.md` shows why (`brd:PAL-06`).

## 2. Concept sentence

One sentence naming the single idea the mark carries, for example "a door left ajar: an invitation, not a gate". If it needs "and", it holds two ideas; pick one (`brd:CNC-02`).

## 3. Shortlist (8 to 12 one-liners)

- Mix **literal** lines (an object from the domain) and **abstract** ones (a motion, a relation, a letterform idea).
- Name the category's 2 or 3 obvious symbols as clichés (for example gears for engineering tools, a shield for security); a cliché stays only with a stated twist.
- Each line is one sentence: what is drawn, and why it carries the concept.

## 4. Scoring

Score each line 0 to 2 on the first four questions and 0 to 4 on the name test (it counts double), write the total (0 to 12) beside it, and choose the top three that are distinct from each other. At least two of the three must be literal lines that score 2 or more on the name test: the first run of this kit chose abstract shapes that passed every check and still meant nothing next to the name.

| Question | Why |
|---|---|
| Does it carry the concept sentence? | Concept before drawing |
| Is it distinct from the named clichés and from known marks? | `brd:LGL-02`, `brd:CRF-05` |
| Can it be drawn with 1 or 2 core elements from primitives? | Primitives first; restraint (op7418) |
| Will it survive 16 px in one colour? | `brd:CRF-01`, `brd:CRF-02` |
| Name test (0 to 4): shown alone, would a stranger link it to the name or to the narrative's world? | Mark-only use (favicon, app icon); `brd:CNC-03` |

The scale and questions are this kit's own choice (assumption; tune after use).

## 5. Hand-off to the designers

Each `brand-designer` gets: the brief path, its one line, its folder. Three different lines, never three takes on one line: the checkpoint compares ideas, not polish.
