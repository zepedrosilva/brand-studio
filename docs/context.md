# Context

Glossary of project terms. Add a term when its meaning is not obvious from the code or differs from common use.

| Term | Definition |
|---|---|
| Narrative | The free text a user starts from: a story, mission, README or pitch. |
| Brief | `brand/brief.md`: the declaration block (name, concept, audience, tone, avoid list, scope, palette roles, positioning), the shortlist and the waivers. |
| Metaphor line | A one-sentence idea for a mark. The shortlist has 8 to 12; three distinct lines become concepts. |
| Concept | One greyscale SVG drawn from one metaphor line, in `brand/concepts/a`, `b` or `c`. |
| Checkpoint | The one hard stop in `/brand-create`: three concepts and a recommendation; nothing continues without the user's pick. |
| Master | `brand/mark.svg`, the picked concept edited into the final mark. Every variant is an edit of it. |
| Kit | Everything made after the pick: variants, palette, wordmark, lockups, optional icons, brand sheet, exports. |
| Scope | A (minimal), B (default) or C (extended); recorded in the brief. |
| Rule ID | `brd:<FAMILY>-<NN>`, for example `brd:CRF-02`. Permanent; cited in every finding. |
| Severity | MUST, SHOULD or MAY. Judgment-only palette, type and positioning rules are never MUST. |
| Status | `pass`, `fail`, `review`, `waived`, `not run` or `n/a`, per finding. |
| Evidence level | What decided a finding: `script`, `render` or `judgment`. |
| Source label | How much weight a rule or number carries: standard, vendor guidance, practitioner opinion, weak or contested evidence, research (strength stated); numbers can also be `verify before release` or `assumption`. |
| Verdict | `fail`, `incomplete`, `pass with findings` or `pass` for a whole review; `incomplete` is never reported as a pass. |
| Waiver | A line in the brief that turns one rule's `fail` into `waived` for one file, until a review date. |
| Name test | `brd:CNC-03`: a blind reviewer guesses what each mark means with no text beside it. |
| Brand design brief | The final page `brand/index.html`, served live during a run and static afterwards. |
| Applications page | `brand/applications.html`: the kit placed in everyday uses, with every colour pair measured. |
| Source ID | `A<n>`, `C<n>` or `T<n>`: a row in `plugin/research/`. |
